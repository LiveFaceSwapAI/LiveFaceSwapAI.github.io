# LiveFaceSwap AI GitHub Developer Hub

Source for [the LiveFaceSwap AI organization Pages site](https://livefaceswapai.github.io/).

The site maps browser-preview and Windows 11 virtual-camera workflows, public feedback, private support, security reporting, and verified public repositories. It is intentionally different from the canonical product README and does not contain private production source code.

## What this repo is for

This repository hosts the official GitHub Pages hub for LiveFaceSwap AI public materials.

- Project homepage and documentation entry: [livefaceswap.ai](https://livefaceswap.ai)
- Desktop workflow for cross-app output: [LiveFaceSwap Desktop (Windows 11)](https://livefaceswap.ai/desktop)
- Canonical public repository and issue tracker: [LiveFaceSwap AI on GitHub](https://github.com/LiveFaceSwapAI/livefaceswap)
- Verified browser-extension source mirror: [LiveFaceSwap Browser Extension on SourceForge](https://sourceforge.net/projects/livefaceswap-browser-extension/)

## Topics covered

- Choosing between the browser preview and Windows 11 Desktop workflows
- Routing LiveFaceSwap Camera output into compatible applications
- Finding official setup guides, public feedback, private support, and security reporting paths
