# LiveFaceSwap AI GitHub Developer Hub

Source for [the LiveFaceSwap AI organization Pages site](https://livefaceswapai.github.io/).

The site maps browser previews and desktop workflows for Windows 11, macOS, and Linux, alongside public feedback, private support, security reporting, and verified public repositories. Windows and macOS support virtual-camera output; Linux currently provides a live preview. This hub is intentionally different from the canonical product README and does not contain private production source code.

## What this repo is for

This repository hosts the official GitHub Pages hub for LiveFaceSwap AI public materials.

- Project homepage and documentation entry: [livefaceswap.ai](https://livefaceswap.ai)
- Desktop workflow: [LiveFaceSwap Desktop](https://livefaceswap.ai/desktop)
- Windows, macOS, and Linux installers: [official GitHub releases](https://github.com/LiveFaceSwapAI/livefaceswap/releases/latest)
- Canonical public repository and issue tracker: [LiveFaceSwap AI on GitHub](https://github.com/LiveFaceSwapAI/livefaceswap)
- Verified browser-extension source mirror: [LiveFaceSwap Browser Extension on SourceForge](https://sourceforge.net/projects/livefaceswap-browser-extension/)

## Topics covered

- Choosing between browser preview and Windows, macOS, or Linux Desktop workflows
- Routing LiveFaceSwap Camera output from Windows or macOS into compatible applications; Linux currently supports preview only
- Finding official setup guides, public feedback, private support, and security reporting paths
